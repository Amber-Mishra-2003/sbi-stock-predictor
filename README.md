## 📌 Overview

**SBI AI Stock Predictor** is a full-stack AI/ML application designed to forecast the next-day closing price of **State Bank of India (SBI)** using historical market data.

The system combines:

- **XGBoost** for gradient-boosted tree-based prediction
- **LSTM** for sequential time-series learning
- An ensemble prediction strategy
- FastAPI REST APIs
- React-based interactive frontend
- Interactive financial charts
- Model retraining functionality
- Prediction history
- AI-powered market assistant
- Cloud deployment using Vercel and Render

The application is designed as a complete end-to-end ML product rather than only a standalone prediction script.
